# Piercer Windows Error & Crash Decoder

Decodificador de códigos NTSTATUS / HRESULT / Win32 e analisador de saída !analyze -v do WinDbg

## Funcionalidades

- **Seções principais**: Decodificador Rápido de Código, Códigos Comuns, Analisador de Log WinDbg (!analyze -v)
- **Ações disponíveis**: 0xC0000005, 0x80070005, 0xC0000034, 0xC0000135, 0xC0000409, 0x80004005
- **Persistência automática**: salva alterações automaticamente no navegador (`localStorage`).
- **Multilíngue**: suporte integrado com botão de troca de idioma (`PT / EN / ES`).

## Como Executar

1. Execute `start.bat` para iniciar o servidor local na porta `8158`, ou abra `index.html` diretamente no navegador.
2. Acesse `http://localhost:8158`.
