# Piercer Windows Error & Crash Decoder

decoder of códigos NTSTATUS / HRESULT / Win32 and analyzer of saída !analyze -v of WinDbg

## Features

- **Main Sections**: decoder fast of code, Códigos Comuns, analyzer of Log WinDbg (!analyze -v)
- **Available Actions**: 0xC0000005, 0x80070005, 0xC0000034, 0xC0000135, 0xC0000409, 0x80004005
- **Auto-Save**: automatically persists changes in the browser (`localStorage`).
- **Multi-Language**: built-in language switcher (`PT / EN / ES`).

## How to Run

1. Run `start.bat` to start the local server on port `8158`, or open `index.html` directly in your browser.
2. Open `http://localhost:8158`.
